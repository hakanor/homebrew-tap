# hakanor/homebrew-tap

Homebrew formulae.

```bash
brew install hakanor/tap/ios-screencast
```

| Formula | |
|---|---|
| [ios-screencast](https://github.com/hakanor/ios-screencast) | Low-latency H.264 screen streaming from an iPhone, including system alerts. Installs `ios-screencast` and `ios-device-frames`. |
